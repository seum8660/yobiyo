# 여비요

국내여비 정산 신청서 작성 도구. 별도 설치·빌드 없이 브라우저에서 바로 열립니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `여비요 인트로.dc.html` | 시작 화면 · 팀/개인 버전 선택 |
| `여비요 팀버전.dc.html` | 출장승인 엑셀 업로드 → 인원별 일비·식비·숙박비·운임 산출 → 신청서 일괄 인쇄 |
| `여비요 개인버전.dc.html` | 내 출장 1건 입력 → 동승자·영수증 첨부 → 신청서 인쇄 |
| `여비요 카드뉴스.dc.html` | 홍보용 카드뉴스 5장 |
| `trip-data.js` | 목적지별 기준 운임표·지명 별칭 |
| `support.js` | 페이지 런타임 |
| `_ds/` | 디자인 시스템 스타일 |

## 실행

파일을 내려받아 `여비요 인트로.dc.html`을 브라우저로 엽니다.
로컬 서버로 띄우려면:

```
python3 -m http.server 8080
```

GitHub Pages로 배포하면 `index.html`이 인트로로 이동시킵니다.

## 계산 기준

- 숙박비 상한: 서울 100,000원 / 6대 광역시 80,000원 / 그 밖의 지역 70,000원 (1박 기준)
- 운임: `trip-data.js`의 목적지별 왕복 기준액. 편도 구간은 1/2 적용
- 동승자는 운임 0원으로 별도 신청서 생성
- 개인 정보(소속·직급·성명·출발지), 서명 이미지, 최근 출장은 브라우저 localStorage에 저장
- 개인버전 서명: 이미지 파일 업로드 또는 마우스로 직접 그리기 (한 번 저장하면 이후 신청서에 자동 삽입)
